# Registro da norma de tradução controlada

## Identidade

| Campo | Valor |
| --- | --- |
| ID documental | `DOC-GOV-POL-TRADUTOR` |
| Norma | `REG-TRAD-001` |
| Versão | `1.0.0-rc.1` |
| Estado | `CANDIDATA_EM_VALIDACAO` |
| Autoridade de conteúdo | arquivo `tradutor.md` da pasta `TRADUTOR` no Google Drive |
| URL | `https://drive.google.com/file/d/1QOLqnLTQFq5jtCju2-Hyu9JBd-ORmkkV/view` |
| SHA-256 | `3dc7adb4fe2da4d2f2c68603667b79ffe2fb3b14501cf3bcbfec9e22e785ff18` |
| Registro | `docs/registry/registro-traducao.yaml` |

Este arquivo é um localizador controlado e não duplica o texto normativo. O conteúdo aplicável é o blob identificado pela URL e pelo SHA-256 acima. Divergência entre o arquivo do Drive e o hash registrado produz `BLOCKED`.

A norma somente pode ser promovida de candidata para vigente após:

1. validação dos schemas, da máquina de estados e do runtime;
2. execução dos testes positivos e negativos;
3. aprovação humana vinculada ao hash;
4. atualização do registro mestre de documentos.
