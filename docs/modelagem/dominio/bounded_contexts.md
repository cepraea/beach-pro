# Bounded contexts — domínio

Bounded Contexts promovidos ao Modelo Canônico (`schemas/schema_elemento_modelo.json`,
`tipo=BOUNDED_CONTEXT`, `estagio=DOMINIO`) — sempre `estado_epistemologico=VALIDADO`, com
`maturidade` atribuída (seção 4.4 do plano).

`CTX-001`–`CTX-008` ainda não aparecem aqui: nasceram `estagio=CANDIDATO`/
`estado_epistemologico=INFERIDO` em `candidatos/bounded_contexts.md` (seção 4.2 do plano) — são
hipóteses estruturais da modelagem de referência, não observações diretas nem fatos já confirmados
por Davi. Só entram aqui depois de reconciliação real com evidência do corpus, via `SEM-NNN`.

Nenhum Bounded Context promovido ainda.
