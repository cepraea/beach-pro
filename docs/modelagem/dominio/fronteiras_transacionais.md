# Fronteiras transacionais — domínio

Fronteiras transacionais promovidas ao Modelo Canônico (`schemas/schema_elemento_modelo.json`,
`tipo=FRONTEIRA_TRANSACIONAL`, `estagio=DOMINIO`) — sempre `estado_epistemologico=VALIDADO`, com
`promoted_from`/`promoted_by` preenchidos.

Nenhuma fronteira transacional promovida ainda.
