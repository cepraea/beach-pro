# Feature: Registro de treinos

Compromissos de treino (MVP-03, M2): criação com data, prazo, vigência,
responsável e próxima ação; eventos passados não aparecem como vigentes;
pendências obrigatórias possuem estado.

Solicitações e respostas (MVP-04, M2): modelo geral de solicitações de
disponibilidade, estados semânticos (sim/não/incerta/não respondida),
justificativa minimizada, alteração dentro do prazo com versão anterior
preservada e correção administrativa rastreável.
