# Feature: Avaliações e cobertura

Cobertura por função ampla (MVP-08, M3): contagem descritiva baseada
exclusivamente nas respostas vigentes. Funções: goleira, defesa, ataque,
especialista e indefinida. Sem recomendação automática de convocação,
escalação, disciplina ou condição pessoal.

Fora de escopo nesta fase: feedback individual (RF-P04) e avaliação
psicológica sensível.
