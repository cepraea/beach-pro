# Feature: Gestão de treinadores

Fundação, identidade e acesso (MVP-01, M1): contas individuais verificadas,
perfis Davi e atleta, MFA TOTP, cadastro por convite, recuperação, suspensão,
RLS e proibição de impersonação.

Histórico e auditoria (MVP-09, M1+M4): rastreabilidade de registros críticos
e trilha mínima de segurança.

Privacidade aplicada (MVP-10, M4): isolamento de dados, proibição de inferência
automática e independência de ferramentas de IA externas.
