# Feature: Controle de presenças

Declaração, lista prevista e presença real (MVP-05, M3): disponibilidade e
presença são entidades distintas; lista de confirmadas é previsão, não
comprovação; Davi pode publicar, substituir, encerrar ou não publicar a lista;
presença real registrada somente após o treino.

Caixa individual da atleta (MVP-06, M4): solicitações pendentes, prazo,
resposta vigente, justificativa, fechamento, histórico e registro de ciência
explícita.

Estado operacional de Davi (MVP-07, M4): visão única de elenco, próximos
treinos, respostas, pendências e fatos ainda não registrados.
